# 1. Installation d'openSSL pour Windows
Il faut d'abord vérifier si openSSL n'est pas déjà installé sur votre ordi :

```shell
openssl version -a
OpenSSL 3.3.0 9 Apr 2024 (Library: OpenSSL 3.3.0 9 Apr 2024)
```

Si la commande précédente ne répond pas, il faut installer openSSL.

Il existe plusieurs versions d'OpenSSL pour Windows. L'un de ces produits est [Win32 OpenSSL](https://slproweb.com/products/Win32OpenSSL.html) . Des options supplémentaires peuvent être trouvées dans le [wiki OpenSSL Binaries](https://wiki.openssl.org/index.php/Binaries) . Lors de l'installation, acceptez les paramètres d'installation par défaut.

> Si openSSL est déjà installé, il a peut-être été installé avec une autre application. Recherchez l'emplacement du fichier de commande openssl.exe pour connaitre l'application qui l'a installé. \
> Dans une console PowerShell tappez :
> ```ps
> get-command openssl | select name,path
> ```
> Ou dans une invite CMD :
> ```cmd
> where openssl
> ```

> Remarque : Win32 OpenSSL est inclu dans MinGW. Si vous utilisez cette version et que vous voulez la mettre à jour, il faut mettre à jour MinGW : [Mettre à jour MinGW avec MSYS2](https://gitlab.com/gwenael.laurent/public/-/blob/master/vscode/vscode-cpp.md#36-mettre-%C3%A0-jour-mingw-w64)


# 2. Installation d'openSSL pour Ubuntu
openSSL est installé par défaut sur la plupart des distributions Linux.

Vérifiez la version :
```shell
openssl version -a
```

Pour mettre à jour avec la dernière version (même commande pour l'installer ou le mettre à jour):
```shell
sudo apt update
sudo apt upgrade
sudo apt install openssl
```

> Doc d'install à partir des sources : https://linuxgenie.net/install-openssl-on-ubuntu-22-04/
