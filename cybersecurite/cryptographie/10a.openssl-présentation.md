# 1. Protocole SSL

Le protocole SSL (Secure Socket Layer) a été développé par la
société Netscape Communications Corporation pour permettre aux
applications client/serveur de communiquer de façon sécurisée. TLS
(Transport Layer Security) est une évolution de SSL réalisée par
l'IETF.

SSL est un protocole qui s'intercale entre TCP/IP et les
applications qui s'appuient sur TCP. Une session SSL se déroule en
deux temps :

1.  une phase de poignée de mains (handshake) durant laquelle le
    client et le serveur s'identifient, conviennent du système de
    chiffrement et d'une clé qu'ils utiliseront par la suite.
2.  la phase de communication proprement dite durant laquelle les
    données échangées sont compressées, chiffrées et signées.

L'identification durant la poignée de mains est assurée à l'aide de
certificats X509.

Ressources : [How to use OpenSSL: Hashes, digital signatures, and more](https://opensource.com/article/19/6/cryptography-basics-openssl-part-2)

# 2. openSSL : Cryptography and SSL/TLS Toolkit

[**OpenSSL**](https://www.openssl.org/) est une **boîte à outils de cryptographie** implémentant les protocoles réseau Secure Sockets Layer (SSL v2/v3) et Transport Layer Security (TLS v1) et les normes de cryptographie associées requises par ceux-ci.

OpenSSL existe sous 2 versions :

1.  une bibliothèque de programmation en C permettant de réaliser
    des applications client/serveur sécurisées s'appuyant sur
    SSL/TLS.
2.  un programme en ligne de commande (`openssl`) permettant d'utiliser les différentes fonctions de cryptographie à partir du shell.

OpenSSL peut être utilisé pour :

- Création et gestion des clés privées, clés publiques et paramètres
- opérations cryptographiques à clé publique
- Création de certificats X.509, CSR et CRL
- Calcul des empreintes (hash / *```digest```*) de message
- Cryptage et décryptage avec des chiffrements (*```ciphers```*)
- Tests de clients et serveurs SSL/TLS
- Traitement du courrier signé ou chiffré S/MIME
- Demandes d'horodatage, génération et vérification


# 3. Aide de openSSL
OpenSSL permet de :
* **calculer l'empreinte d'un document :**\
  (FR) Empreinte, résumé, `hash` = (EN) `digest`
* **chiffrer ou déchiffrer un document :**\
  (FR) Chiffrer = (EN) : `encryption`\
  (FR) message chiffré, cryptogramme = (EN) `Cypher`


La syntaxe générale de la commande openssl est

```bash
openssl <commande> <options>
```

L'aide de openssl est obtenue en ajoutant l'option `-help` :

```sh
openssl -help
```

Aide sur les commandes d'empreintes (digest) :
```sh
openssl dgst -help
```

Aide sur les commande de chiffrement (encryption ) :
```sh
openssl enc -help
```
