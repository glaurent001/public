# 1. Objectifs
* Le serveur websocket (broker) sera écrit en Node.js. 
* Il écoutera sur le port 8100. 
* Il sera hébergé dans un sous dossier de votre site CodeIgniter principal : ```/home/[compte]/public/wss/wss.js```

Exemple :
* Site principal PHP CodeIgniter : [compte].alwaysdata.net
* Site pour le serveur websocket : [compte].alwaysdata.net/wss

# 2. Documentation servant d'exemple
Doc source : https://blog.alwaysdata.com/fr/2023/03/14/accrochez-vous-a-vos-chaussettes-hebergement-de-donnees-a-grande-vitesse-avec-websockets/

> Notre exemple est tout simple : une fois connecté, notre client pourra envoyer le message ping au serveur, qui renverra alors pong à tous les clients connectés, une seconde plus tard.

# 3. Créer le serveur websocket
Dans votre projet CodeIgniter, créez le sous dossier ```/home/[compte]/public/wss/```

Dans le dossier `.../public/wss/`, crééz le fichier` wss.js` avec le code de test suivant :
```js
import WebSocket, { WebSocketServer } from 'ws';

const wss = new WebSocketServer({
  host: process.env.IP || '',
  port: process.env.PORT || 8100
});

wss.on('connection', (ws) => {
  // log as an error any exception
  ws.on('error', console.error);
});

wss.on('connection', (ws) => {
  /* ... */
  ws.on('message', (data) => {
    // only react to `ping` message
    if (data != 'ping') { return }
    wss.clients.forEach((client) => {
      // send to active clients only
      if (client.readyState != WebSocket.OPEN) { return }
      setTimeout(() => client.send('pong'), 1000);
    });
  });
});
```

Ouvrez un terminal dans le dossier `.../public/wss/` pour installer la librairie [websockets/ws](https://github.com/websockets/ws) :

```sh
npm install ws
```

Modifiez le fichier package.json pour permettre l'utilisation du module ws :
```json
{
  "type": "module",
  "dependencies": {
    "ws": "^8.18.0"
  }
}
```
Si vous voulez tester le serveur websocket sur votre PC de dév :
```sh
node wss.js
```

# 4. Transférer le serveur sur votre hébergement alwaysdata
Connectez vous en SSH sur votre serveur où votre appli CodeIgniter est déployée.

Créez le dossier ```/home/[compte]/public/wss/```
```sh
cd ~/public
mkdir wss
chmod 755 wss
```
Transférez les fichiers `wss.js` et `package.json` dans ce nouveau dossier (en SFTP avec mozilla par exemple)

Toujours en SSH dans le dossier ```/home/[compte]/public/wss/```, installez les dépendances citées dans package.json

```sh
npm install
```

# 5. Créer un site alwaysdata pour exécuter votre serveur WebSocket
Dans l'interface d'administration : Web > Sites > Ajouter un site
* Adresses : [compte].alwaysdata.net/wss
* Configuration :
  * **Type : Node.js**
  * Commande : node $HOME/public/wss/wss.js
  * Répertoire de travail : /home/[compte]/public/wss/
  * Environnement : PORT=8100
  * Version de Node.js : 22
* Valider

Dans l'interface d'administration : Web > Sites > [compte].alwaysdata.net/wss > Modifier > Avancé
* Temps d'inactivité : 0 (pour que le serveur ne s'arrête jamais)
* Exclure le chemin : cocher la case
* Valider

# 6. Test du serveur websocket
Dans une vue de votre projet CodeIgniter, insérer le code javascript suivant (en ajustant l'adresse de votre site):
```js
<script>
    WS_SERVER = '[compte].alwaysdata.net/wss/:8100'
    dateFormatter = new Intl.DateTimeFormat('en-US', {
        hour: "numeric",
        minute: "numeric",
        second: "numeric"
    })

    const websocket = new WebSocket(`wss://${WS_SERVER}`)

    const ping = (msg) => {
        msg = msg || 'ping'
        console.log("Send message", msg)
        websocket.send(msg)
    }

    websocket.addEventListener('message', ({ data }) => {
        console.log("Recv message", data, dateFormatter.format(Date.now()))
    })

    websocket.addEventListener('open', () => ping())</script>
```

Affichez cette vue dans un navigateur et ouvrez les devtools > Console

Vous devriez voir apparaître les messages de ping/pong dans la console. Essayez en exécutant manuellement la fonction `ping()` dans les devtools.
