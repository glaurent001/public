# 1. Prérequis
Avant d'utiliser ce tuto, assurez vous d'avoir :
* Installé Ubuntu
* Mis à jour l'OS : `sudo apt update && sudo apt upgrade`
* Installé et configuré un serveur SSH
* Installé et configuré le serveur web apache2
* Installé le module PHP

> **Remarque** : Dans ce tuto, j'utilise Ubuntu 24.04.4 LTS dans une VM virtualbox\
> -utilisateur : admin-a01\
> -nom de machine : admin-a01-VirtualBox\
> -addresse IP de la VM Ubuntu : 172.16.111.87 (client DHCP)


# 2. Présentation de LAMP
LAMP est l'acronyme de ```Linux Apache MySQL PHP```.

Installer LAMP sur Linux correspond à :
* installer le serveur web Apache
* installer le module PHP d'Apache
* **installer le serveur de bases de données MySQL (ou MariaDB)**
* installer phpMyAdmin (site web d'administration de MySQL)
* fournir un moyen pour mettre à jour les fichiers du site web (SFTP)


> MariaDB est fork communautaire de MySQL avec la volonté de rester un logiciel libre. Il s'utilise exactement comme MySQL.\
> L'exécutable du **serveur/daemon** s'appelle ```mariadbd```\
> L'exécutable du **client** s'appelle ```mariadb```

![MariaDB Logo](img/mariadb-logo.png)

# 3. Installation de mariadb
Installation de MariaDB serveur, et de la version cliente:
```shell
$ sudo apt install mariadb-server mariadb-client
```

Il faut maintenant configurer la sécurité pour les accès à MariaDB. Pour cela, il faut exécuter :
```shell
$ sudo mysql_secure_installation
```

* Enter current password for root (enter for none) --> (Entrée) 
* Switch to unix_socket authentication [Y/n] --> (n)
* Change the root password? [Y/n] --> (Y)
  * Saisir 2 fois le mot de passe de de l'utilisateur root mysql (et notez le !)
* Remove anonymous users? [Y/n] --> (Y)
* Disallow root login remotely? [Y/n] --> (Y)
* Remove test database and access to it? [Y/n] --> (Y)
* Reload privilege tables now? [Y/n] --> (Y)

Pour prendre en compte les modifs de sécurité :
```shell
$ sudo systemctl daemon-reload
```
# 4. Vérification de l'installation
Vérifiez la version du serveur MariaDB installée :
```shell
$ mariadbd --version
mariadbd  Ver 10.11.14-MariaDB-0ubuntu0.24.04.1 for debian-linux-gnu on x86_64 (Ubuntu 24.04)
```

Vérifiez si le daemon ```mariadbd``` est démarré (dans les processus). S'il est démarré, vous devriez voir le processus ```/usr/sbin/mariadbd```
```ssh
$ ps -ef | grep mariadbd
mysql       4151       1  0 18:19 ?        00:00:01 /usr/sbin/mariadbd
admin-a+    4738    3223  0 18:26 pts/0    00:00:00 grep --color=auto mariadbd
```

Vérifiez si le daemon ```mariadbd``` est démarré (avec systemctl) :
```shell
$ systemctl status mariadb
● mariadb.service - MariaDB 10.11.14 database server
     Loaded: loaded (/usr/lib/systemd/system/mariadb.service; enabled; preset: enabled)
     Active: active (running) since Thu 2026-03-26 18:19:30 CET; 14min ago
       Docs: man:mariadbd(8)
             https://mariadb.com/kb/en/library/systemd/
   Main PID: 4151 (mariadbd)
     Status: "Taking your SQL requests now..."
      Tasks: 9 (limit: 30345)
     Memory: 78.7M (peak: 81.8M)
        CPU: 2.532s
     CGroup: /system.slice/mariadb.service
             └─4151 /usr/sbin/mariadbd
```

Testez le port d'écoute de MariaDB avec avec **```ss (anciennnement netstat)```**. Par défaut, mariadb écoute sur le port **TCP/3306** uniquement à partir de 127.0.0.1 ([doc des commandes netstat et ss ici](https://linuxize.com/post/check-listening-ports-linux/)) :
```ssh
$ sudo ss -tunlp | grep mariadbd
tcp   LISTEN 0      80         127.0.0.1:3306       0.0.0.0:*    users:(("mariadbd",pid=4151,fd=24))
```

# 5. Tester l'accès au serveur SQL
Tester l'accès au serveur MariaDB à partir du client console de MariaDB (exécutable mariadb) :
```shell
$ mariadb -h localhost -u root -p
Enter password: 
Welcome to the MariaDB monitor.  Commands end with ; or \g.
Your MariaDB connection id is 39
Server version: 10.11.14-MariaDB-0ubuntu0.24.04.1 Ubuntu 24.04

Copyright (c) 2000, 2018, Oracle, MariaDB Corporation Ab and others.

Type 'help;' or '\h' for help. Type '\c' to clear the current input statement.

MariaDB [(none)]>
```
Vous pouvez visualiser les bases de données déjà présentes sur MariaDB :
```sql
MariaDB [(none)]> show databases;
+--------------------+
| Database           |
+--------------------+
| information_schema |
| mysql              |
| performance_schema |
| sys                |
+--------------------+
4 rows in set (0,001 sec)

```
Pour quitter le client MariaDB :
```sql
MariaDB [(none)]> quit
Bye
```

# 6. (Option à éviter) Activer les accès distants à mariadb
Par défaut, pour des raisons de sécurité, les accès distants (remote access) ne sont pas autorisés. Le serveur mariadbd n'accepte les connexions qu'à partir de localhot. On dit qu'il "écoute" sur 127.0.0.1:3306. Le client et le serveur doivent donc s'exécuter sur la même machine.

> **Dans le cadre de l'installation d'un LAMP, vous ne devez pas activer les accès distants à mariadb** puisque les connexions BDD se feront à partir du code PHP, et que PHP s'exécute sur la même machine que mariadb.

Si toutefois vous avez besoin d'autoriser les accès distants à mariadb (à justifier), il faut modifier un fichier de configuration du serveur mariadbd :

```shell
$ sudo nano /etc/mysql/mariadb.conf.d/50-server.cnf
```
Modifier la propiété ```bind-address``` :
```conf
bind-address = 0.0.0.0
```

Redémarrer le serveur mariadb pour le forcer à relire ses fichiers de configuration :
```shell
$ sudo systemctl restart mariadb
```

Testez le port d'écoute de MariaDB. Maintenant mariadb écoute sur le port **TCP/3306** à partir de n'importe quelle adresse IP (**0.0.0.0**)
```shell
$ sudo ss -tunlp | grep mariadbd
tcp   LISTEN 0      80           0.0.0.0:3306       0.0.0.0:*    users:(("mariadbd",pid=5325,fd=24)) 
```
Evidemment, il reste à créé un utilisateur mariadb avec les droits d'accès à distance. Vous pouvez le faire simplement grâce à phpmyadmin.
