# 4. Installer les additions de VirtualBox
Ouvrez un terminal pour installer `bzip2`, `tar`, `gcc`, `make` et `perl`
```bash
$ sudo apt install bzip2 tar gcc make perl
```

* Dans la VM lancée > Menu de la VM "Périphériques" > Insérer l'image CD des Additions invité ...

# 6. Firewall UFW
Ubuntu possède par défaut un firewall logiciel qui s'appelle [**```UFW Uncomplicated Firewall```**](https://doc.ubuntu-fr.org/ufw). 

Vérifiez s'il est activé :
```
$ sudo ufw status
```
Pour l'arrêter ou le démarrer :
```
$ sudo ufw disable
$ sudo ufw enable
```
S'il est activé, ce firewall bloque toutes les requêtes venant de l'extérieur de la machine. 

Pour accéder au serveur web installé sur Ubuntu, il faudra donc configurer UFW pour autoriser les requêtes entrantes sur le port 80 (HTTP) et sur le port 443 (HTTPS). 

> Dans les commandes suivantes on utilise les variables http et https qui sont définies parmi les ports bien connus (fichier ```/etc/services```)

```shell
$ sudo ufw allow http
$ sudo ufw allow https
```
Pour voir la configuration du firewall UFW :
```shell
$ sudo ufw status verbose
```

# 8. Installer le navigateur web Chromium
> Vous pouvez l'installer à partir du Dash en cliquant sur "Centre d'applications" ou en ligne de commande comme suit :

Mettre à jour le système :
```shell
$ sudo apt update
$ sudo apt upgrade
```
Installer Chromium depuis les dépôts officiels :
```shell
$ sudo apt install chromium-browser -y
```
Vérifier la version de Chromium :
```shell
$ chromium-browser --version
```
Démarrer Chromium :
```shell
$ chromium
```
ou à partir de l'interface graphique : Afficher les applications > Navigateur Web Chromium
