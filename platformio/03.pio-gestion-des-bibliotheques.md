# Library Dependency Finder (LDF)
Quand le code source contient une dictive d'inclusion ```#include ...```, il y a plusieurs endroits où platformIO cherche les bibliothèques correspondantes.  

**Dans l'ordre** :
* lib_extra_dirs
* lib_dir
* libdeps_dir
* “core_dir/lib”
* frameworks et SDKs

[Doc officielle](https://docs.platformio.org/en/latest/librarymanager/ldf.html)

# 1. lib_extra_dirs
Dossiers externes au projet explicitement listés dans le fichier de configuration du projet  ```platformio.ini```
```ini
[env:myenv]
lib_extra_dirs =
    /common/libraries
    /iot/libraries
```

# 2. lib_dir
Dans le dossier ```/lib``` du projet. 

C'est l'endroit à utiliser pour les bibliothèques que vous codez (bibliothèques et classes privées)

Les bibliothèques doivent être organisées de la façon suivante :
```
|--lib
|  |--Bar
|  |  |--docs
|  |  |--examples
|  |  |--src
|  |     |- Bar.c
|  |     |- Bar.h
|  |--Foo
|  |  |- Foo.c
|  |  |- Foo.h
|- platformio.ini
|--src
   |- main.c
```
Remarque : Il n'y a rien à ajouter au fichier de configuration du projet ```platformio.ini```.

# 3. libdeps_dir
Dans le dossier ```/.pio/libdeps``` du projet. 

C'est ici que s'installent les bibliothèques ``téléchargées à partir d'un dépôt en ligne``. L'installation se fait à partir du menu `libraries` de platformIO.

Le fichier de configuration du projet ```platformio.ini``` doit contenir le nom des bibliothèques à utiliser
```ini
[env:myenv]
lib_deps = bblanchon/ArduinoJson@^6.17.2
```

# 4. "core_dir/lib"
Dans le dossier du profil utilisateur ```C:\Users\gwenael\.platformio\lib```. 

C'est l'emplacement des bibliothèques stockées en **```global```**, c'est à dire utilisable par tous les projets (sans avoir besoin d'en faire une copie dans le projet ou de les re-télécharger). C'est l'endroit adéquat pour les bibliothèques ````téléchargées à partir d'un dépôt en ligne```` et que vous utilisez souvent dans vos projets.

Le fichier de configuration du projet ```platformio.ini``` doit contenir le nom des bibliothèques à utiliser
```ini
[env:myenv]
lib_deps = ArduinoJson
```

L'installation se fait en ligne de commande dans un terminal **```PlatformIO CLI```**. 

Dans VScode, ce terminal s'affiche à partir de la barre d'activités > PlatformIO > Quick Access > Miscellaneous > PlatformIO Core CLI

[Documentation PlatformIO CLI](https://docs.platformio.org/en/latest/librarymanager/quickstart.html#platformio-core)

Exemple pour installer en global la bibliothèque ArduinoJson :
* lister les bibliothèques installées en global
```
pio lib -g list
```
* chercher le bibliothèques contenant la chaine "json"
```
pio lib search json

ArduinoJson
===========
#ID: 64
A simple and efficient JSON library for embedded C++. ...
```
* installer la bibliothèque avec l'ID affiché dans les résultats de recherche
```
pio lib -g install 64
```
* Pour mettre à jour la bibliothèque
```
pio lib -g pudate ArduinoJson
```
* pour désinstaller la bibliothèque
```
pio lib -g uninstall ArduinoJson
```

# 5. frameworks et SDKs
Dans le dossier du framework ou du SDK.

Pour les bibliothèques incluses dans le framework.

Pas besoin de modifier Le fichier de configuration du projet ```platformio.ini```.

Exemple pour utiliser  ```#include <Arduino.h>```. 
* Si le projet est créé pour une carte ```ESP32``` avec le framework Arduino, plateformIO trouvera la bibliothèque dans :
  ```
  C:\Users\gwenael\.platformio\packages\framework-arduinoespressif32\cores\esp32
  ```

* Si le projet est créé pour une carte ```ESP8266``` avec le framework Arduino, plateformIO trouvera la bibliothèque dans :
  ```
  C:\Users\gwenael\.platformio\packages\framework-arduinoespressif8266\cores\esp8266
  ```

* Si le projet est créé pour une carte ```arduino nano``` avec le framework Arduino, plateformIO trouvera la bibliothèque dans :
  ```
  C:\Users\gwenael\.platformio\packages\framework-arduino-avr\cores\arduino
  ```
