# 1. Définition
📌 Un timer est une **minuterie électronique**. Il déclenche une fonction de callback (une interruption logicielle) quand le temps d'attente choisi est atteind.

Chaque ESP32 possède 4 timers matériels (ESP Timer). Ces timers sont des composants indépendants du processeur. Ils s'occupent de compter le temps pendant que le programme principal peut exécuter d'autres fonctions.

On peut configurer les timers de 2 façons :
* **One-Shot** : le timer déclenche une interruption après un temps défini puis s'arrête
* **Périodique** : le timer déclenche une interruption après un temps défini puis est redémarré automatiquement avec le même temps d'attente jusqu'à la prochaine interruption.

> Les timers sont des composants non bloquants qui permettent de remplacer avantageusement la fonction bloquante delay()

# 2. Procédure générale pour utiliser les timers
> La bibliothèque utilisée dans les exemples suivants est inclue dans le framework ESP-IDF et s"appelle "**ESP Timer (High Resolution Timer)**".\
> _Ce n'est pas la même que celle du framework arduino qui s'appelle "[Arduino-ESP32 Timer API](https://docs.espressif.com/projects/arduino-esp32/en/latest/api/timer.html)"_.

**ESP Timer** est disponible dans vos programmes PlatformIO/Arduino sans installation particulière, il suffit d'inclure :
```cpp
#include <Arduino.h>
#include "esp_timer.h"
```


1. Créer un timer
   * Déclarer un objet `esp_timer_handle_t`
   * Créer la fonction de callback du timer
   * Paramétrer le timer en utilisant une structure `esp_timer_create_args_t` qui inclue le nom de la fonction de callback
   * Créer le timer avec la fonction `esp_timer_create()`
2. Démarrer le timer en mode one-shot ou en mode périodique
   * En mode One-Shot : appeler la fonction `esp_timer_start_once()`
   * En mode périodique : appeler la fonction `esp_timer_start_periodic()`
3. Arrêter le timer pendant son fonctionnement avec la fonction `esp_timer_stop()`
4. Supprimer le timer quand il n'est plus utilisé avec la fonction `esp_timer_delete()`


# 3. Timer périodique
📌 Un timer périodique appelle sa fonction de rappel à expiration et **redémarre automatiquement**, ce qui a pour effet d'appeler la fonction de rappel à intervalle défini jusqu'à ce que la minuterie soit arrêtée manuellement.

> Les minuteries périodiques sont utiles pour les actions répétitives, telles que l'échantillonnage de données de capteurs, la mise à jour d'informations d'affichage ou la génération d'une forme d'onde.

Exemple de codage avec un timer périodique qui se déclenche toutes les secondes.

```cpp
#include <Arduino.h>
#include "esp_timer.h" // Pour utiliser les timers

esp_timer_handle_t mon_timer_handle; // Timer handle
uint64_t timer_delay = 1000 * 1000;  // en µs (=1s)
// Variables déclarées comme volatiles car mises à jour
// par le programme principal ET/OU le timer
volatile bool flag_fin_du_timer = false;

// Gestion des sections critiques (MUTEX)
portMUX_TYPE timerMux = portMUX_INITIALIZER_UNLOCKED;

/****** Gestionnaire du Timer ******/
void IRAM_ATTR mon_timer_callback(void *arg)
{
  // Attention : le temps d'exécution de cette fonction doit être
  // le plus court possible et inférieur à la périodicité du timer
  portENTER_CRITICAL(&timerMux); // début section critique
  flag_fin_du_timer = true;      // Fin d'attente du timer
  portEXIT_CRITICAL(&timerMux);  // fin section critique
}

/****** setup ******/
void setup()
{
  Serial.begin(115200);

  // Configuration du timer périodique
  // - se déclenche toutes les secondes
  // - déclenche l'exécution de la fonction mon_timer_callback()
  const esp_timer_create_args_t mon_timer_args = {
      .callback = &mon_timer_callback,
      .name = "mon_timer"};
  esp_timer_create(&mon_timer_args, &mon_timer_handle);
  esp_timer_start_periodic(mon_timer_handle, timer_delay);
}

/****** loop ******/
void loop()
{
  bool demandeTraitementTimer = false;

  portENTER_CRITICAL(&timerMux); // début section critique
  if (flag_fin_du_timer == true)
  {
    demandeTraitementTimer = true;
    flag_fin_du_timer = false; // réinitialiser le flag de fin de timer
  }
  portEXIT_CRITICAL(&timerMux); // fin section critique

  if (demandeTraitementTimer == true)
  {
    demandeTraitementTimer = false;
    // actions à effectuer à chaque période du timer
    Serial.println("Fin de Timer");
  }
  delay(1);
}
```

# 4. Timer One-Shot
📌 Un timer à usage unique **n'exécute sa fonction de rappel qu'une seule fois**, à l'expiration du délai, puis cesse de fonctionner.

> Ce type de minuteur est utile pour les actions ponctuelles ou différées, comme l'arrêt d'un appareil ou la lecture d'un capteur après un intervalle de temps ou à un instant précis.
