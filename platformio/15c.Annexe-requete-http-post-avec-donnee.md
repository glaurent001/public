# Annexe : Requête HTTP POST avec données

> * Auteur : Gwénaël LAURENT
> * Date : 27/09/2021

# 1. Mise en situation
* Communication entre **```ESP```** (client HTTP en C++) et **```API web```** (serveur HTTP en PHP).
* Le client HTTP envoie une **```requête POST avec données```** à l'API Web.

Il existe 2 méthodes pour transférer les données. Cela nécessite une codage différent côté ESP ET côté API Web


# 2. Activer le débugage PHP de l'API dans VScode
> Le debug vous permettra de vérifier le fonctionnement de la communication.

1. Lancer le debug PHP dans VScode
2. Activer le debug sur l'ESP en ajoutant une QueryString à l'URL de l'API

Code ESP :
```cpp
String urlPost = "http://172.16.128.120/bdd_test/ws/temperatures/insert.php?XDEBUG_SESSION_START=vscode";
```

# 3. Envoi des données à la manière d'un formulaire HTML
Il faut adapter l'en-tête HTTP pour que l'API recoivent les données dans la superglobale $_POST[]

Code ESP :
```cpp
//ajout des en-têtes HTTP
clientHTTP.addHeader("Content-Type", "application/x-www-form-urlencoded");
//donnée à envoyée au format "Formulaire POST"
String postFormData = "idb=1&degre=11.3";
httpCode = clientHTTP.POST(postFormData.c_str());
```

Code API Web :
```php
$idb = urldecode($_POST["idb"]);
$degre = urldecode($_POST["degre"]);
```
Remarque : les valeurs des variables de formulaire peuvent aussi contenir du format JSON

# 4. Envoi des données en mode brut (mode RAW)
* Adapté aux données formatées en JSON.
* La donnée JSON ne porte pas de nom de variable.
* Les données ne sont pas reçues dans les superglobales.

Code ESP :
```cpp
//ajout des en-têtes HTTP
clientHTTP.addHeader("Content-Type", "application/json");
//donnée à envoyée en mode RAW + encodage JSON
String postJson = "{\"sensorValue\":\"11.3\"}";
httpCode = clientHTTP.POST(postJson.c_str());
```

Code API Web :
```php
//données reçues en mode RAW
$donnee = strval(urldecode(file_get_contents('php://input')));
$jsonData = json_decode($donnee);
$value = htmlspecialchars($jsonData->sensorValue);
```
