# 1. Définition
📌 Un **compteur d'impulsions (Pulse Counter, PCNT)** est conçu pour compter le nombre de fronts montants et/ou descendants des signaux d'entrée.

Chaque ESP32 possède 8 compteurs d'impulsions matériels (PCNT_UNIT_0 à PCNT_UNIT_7). **Ils peuvent être configurés pour déclencher une interruption matérielle quand la valeur du compteur atteint un certain seuil**.

> Ces compteurs sont des composants indépendants du processeur. Ils s'occupent de compter le nombre d'impulsion reçues sur une broche pendant que le programme principal peut exécuter d'autres fonctions.

Un module PCNT peut généralement être utilisé dans des scénarios tels que :
* Calculer la fréquence d'un signal périodique en comptant le nombre d'impulsions dans un intervalle de temps (fréquence max du signal = 40MHz).
* Interfacer un compteur d'eau qui génère des impulsions correspondants au volume d'eau qui le traverse (mesure de la consommation et/ou du débit).


# 2. Quelques informations sur les compteurs de l'ESP32
📑 **Bibliothèque**
> La bibliothèque utilisée dans les exemples suivants est inclue dans le framework ESP-IDF et s'appelle "**PCNT**".

PCNT est disponible dans vos programmes PlatformIO/Arduino sans installation particulière, il suffit d'inclure :
```cpp
#include <Arduino.h>
#include "driver/pcnt.h"
```
---
📑 **Valeur maximale**\
Le nombre d'impulsion comptées est disponible dans un entier sur 16 bits. La valeur maximale du compteur est donc de 65535. Quand il atteint cette valeur, il recommence automatiquement à 0.

---
📑 **Pull-up ou pull-down**\
Il n'est pas nécessaire d'appeler pinMode(...) pour configurer le mode de fonctionnement de la broche GPIO qui sert au comptage, la config du PCNT s'en occupe automatiquement.\
Cependant, la broche GPIO peut être reconfigurée pour pull-up ou pull-down après l'initialisation de PCNT.

---
📑 **Filtre anti-bruit**\
Les compteurs de l'ESP intègrent un filtre qui permet d'éliminer les "parasites". Il agit comme un mini filtre anti-rebond en éliminant les impulsions parasites qui peuvent suivre une "vrai" impulsion. On peut le configurer pour qu'il ne prennnent pas en compte les impulsions suivantes dans un délai max de  12.8 µs.

# 3. Exemples de codage
## 3.1. Lire le nombre d'impulsions du PCNT
Dans l'exemple suivant, un compteur est configuré et démarré dans la fonction `setup()`. Il compte les fronts montants du signal reçu sur GPIO16.

Le seuil max du compteur n'est pas configuré.
```cpp
pcnt_config.counter_h_lim = 0;
```

La fonction `loop()` lit la valeur du compteur et la remet à zéro si elle dépasse 10. 

```cpp
#include <Arduino.h>
#include "driver/pcnt.h"

// Constantes pour le PCNT
#define PULSE_INPUT_PIN 16       // n° GPIO qui sert au comptage d'impulsions
#define NUM_COMPTEUR PCNT_UNIT_0 // Choix du compteur, ici c'est le n°0

void setup()
{
    Serial.begin(115200);

    // Configuration principale du compteur
    pcnt_config_t pcnt_config;       // structure C qui sert à configurer le compteur
    pcnt_config.unit = NUM_COMPTEUR; // Choix du compteur matériel utilisé
    pcnt_config.channel = PCNT_CHANNEL_0;
    pcnt_config.pulse_gpio_num = PULSE_INPUT_PIN;  // Pin d'entrée
    pcnt_config.ctrl_gpio_num = PCNT_PIN_NOT_USED; // Pas de signal de contrôle
    pcnt_config.pos_mode = PCNT_COUNT_INC;   // Incrémenter le compteur sur les fronts montants
    pcnt_config.neg_mode = PCNT_COUNT_DIS;   // Ne pas compter sur les fronts descendants
    pcnt_config.lctrl_mode = PCNT_MODE_KEEP; // Garder le même mode de comptage
    pcnt_config.hctrl_mode = PCNT_MODE_KEEP; // Garder le même mode de comptage
    pcnt_config.counter_h_lim = 0;           // Valeur max du compteur (sur 16 bits)
    pcnt_config.counter_l_lim = 0;           // Valeur min du compteur (sur 16 bits)

    // Appliquer la configuration principale du compteur
    pcnt_unit_config(&pcnt_config);

    // Activer le filtre anti-bruit (anti-rebond) avec la valeur maximale
    // (1023 cycles de l'horloge APB => 1023 * 12.5ns = 12.8 µs)
    pcnt_set_filter_value(NUM_COMPTEUR, 1023);
    pcnt_filter_enable(NUM_COMPTEUR);

    // RAZ et démarrage du compteur
    pcnt_counter_pause(NUM_COMPTEUR);  // Pause pour initialiser
    pcnt_counter_clear(NUM_COMPTEUR);  // Remettre à zéro la valeur du compteur
    pcnt_counter_resume(NUM_COMPTEUR); // Reprendre le comptage

    Serial.println("PCNT configuré et démarré");
}

void loop()
{
    // Lire la valeur actuelle du compteur
    int16_t count = 0;
    pcnt_get_counter_value(NUM_COMPTEUR, &count);

    // Afficher la valeur du compteur
    Serial.println(String("Valeur du compteur : ") + String(count));

    // Reset du compteur si on atteind 10 impulsions
    if (count >= 10)
    {
        Serial.println("Seuil atteint, remise à zéro du compteur");
        pcnt_counter_clear(NUM_COMPTEUR); // Réinitialiser le compteur
    }

    // Attendre un peu avant de lire à nouveau (100ms ici)
    delay(100);
}
```

## 3.2. Déclencher une interruption quand un seuil est atteint
Dans l'exemple suivant, un compteur est configuré et démarré dans la fonction `setup()`. Il compte les fronts montants du signal reçu sur GPIO16.

Le seuil max du compteur est fixé à 10.
```cpp
pcnt_config.counter_h_lim = 10;
```
Une interruption est configurée pour qu'elle se déclenche quand le compteur atteint la valeur `counter_h_lim`.

Le gestionnaire d'interruption `handleInterruptPcnt()` doit contenir un code aussi rapide que possible. Ici il positionne une variable volatile qui sera traitée dans la fonction `loop()`.

> Les explications sur les variables `volatile` et la gestion des sections critiques se trouvent dans le document [Gestion des interruptions sur ESP32](27.interruptions.md)

```cpp
#include <Arduino.h>
#include "driver/pcnt.h"

// Constantes pour le PCNT
#define PULSE_INPUT_PIN 16       // n° GPIO qui sert au comptage d'impulsions
#define NUM_COMPTEUR PCNT_UNIT_0 // Choix du compteur, ici c'est le n°0

// flag de seuil max atteind
volatile bool vol_seuilAtteind = false;

// Gestion des sections critiques (MUTEX)
portMUX_TYPE cmptMux = portMUX_INITIALIZER_UNLOCKED;

/********* Gestionnaire d'interruption quand le seuil max (H_LIM) est atteind ***********/
void IRAM_ATTR handleInterruptPcnt(void *arg)
{
    portENTER_CRITICAL_ISR(&cmptMux); // début section critique
    vol_seuilAtteind = true;              // accès à la variable volatile
    portEXIT_CRITICAL_ISR(&cmptMux);  // fin section critique
}

void setup()
{
    Serial.begin(115200);

    // Configuration principale du compteur
    pcnt_config_t pcnt_config;       // structure C qui sert à configurer le compteur
    pcnt_config.unit = NUM_COMPTEUR; // Choix du compteur matériel utilisé
    pcnt_config.channel = PCNT_CHANNEL_0;
    pcnt_config.pulse_gpio_num = PULSE_INPUT_PIN;  // Pin d'entrée
    pcnt_config.ctrl_gpio_num = PCNT_PIN_NOT_USED; // Pas de signal de contrôle
    pcnt_config.pos_mode = PCNT_COUNT_INC;         // Incrémenter le compteur sur les fronts montants
    pcnt_config.neg_mode = PCNT_COUNT_DIS;         // Ne pas compter sur les fronts descendants
    pcnt_config.lctrl_mode = PCNT_MODE_KEEP;       // Garder le même mode de comptage
    pcnt_config.hctrl_mode = PCNT_MODE_KEEP;       // Garder le même mode de comptage
    pcnt_config.counter_h_lim = 10;                // Valeur max du compteur (sur 16 bits)
    pcnt_config.counter_l_lim = 0;                 // Valeur min du compteur (sur 16 bits)

    // Appliquer la configuration principale du compteur
    pcnt_unit_config(&pcnt_config);

    // Activer le filtre anti-bruit (anti-rebond) avec la valeur maximale
    // (1023 cycles de l'horloge APB => 1023 * 12.5ns = 12.8 µs)
    pcnt_set_filter_value(NUM_COMPTEUR, 1023);
    pcnt_filter_enable(NUM_COMPTEUR);

    // Déclencher une interruption quand le seuil max (H_LIM) est atteind
    pcnt_event_enable(NUM_COMPTEUR, PCNT_EVT_H_LIM);               // choisir l'événement d'interruption
    pcnt_isr_service_install(ESP_INTR_FLAG_LEVEL1);                // installer le service d'interruption
    pcnt_isr_handler_add(NUM_COMPTEUR, handleInterruptPcnt, NULL); // associer la fonction ISR

    // RAZ et démarrage du compteur
    pcnt_counter_pause(NUM_COMPTEUR);  // Pause pour initialiser
    pcnt_counter_clear(NUM_COMPTEUR);  // Remettre à zéro la valeur du compteur
    pcnt_counter_resume(NUM_COMPTEUR); // Reprendre le comptage

    Serial.println("PCNT configuré et démarré");
}

void loop()
{
    bool affichageSeuil = false;
    portENTER_CRITICAL_ISR(&cmptMux); // début section critique
    if (vol_seuilAtteind == true)
    {
        affichageSeuil = true;
        vol_seuilAtteind = false;
    }
    portEXIT_CRITICAL_ISR(&cmptMux); // fin section critique

    if (affichageSeuil == true)
    {
        Serial.println("Seuil atteint !");
    }

    delay(1);
}

```

## 3.3. Compter le nombre d'impulsions par seconde (PCNT + Timer)
> _Remarque : Cet exemple peut servir de base pour interfacer un compteur d'eau qui génère des impulsions._

Dans l'exemple suivant, la fonction `setup()` démarre un compteur sans activer d'interruption . Il compte les fronts montants du signal reçu sur GPIO16.

Le seuil max du compteur n'est pas configuré.
```cpp
pcnt_config.counter_h_lim = 0;
```
La fonction `setup()` démarre également un Timer périodique qui déclenche sa fonction de rappel `timer_callback()` toutes les 10 secondes.

La fonction `timer_callback()` :
1. enregistre le nombre d'impulsions comptées dans la variable volatile `vol_valeur_compteur`, 
2. remet à zéro le compteur et 
3. positionne une variable volatile `vol_fin_du_timer` qui sera traitée dans la fonction `loop()`.

La fonction `loop()` affiche le nombre d'impulsions comptées pendant les 10 dernières secondes.

> Les explications sur les variables `volatile` et la gestion des sections critiques se trouvent dans le document [Gestion des interruptions sur ESP32](27.interruptions.md)

```cpp
#include <Arduino.h>
#include "driver/pcnt.h" // Pour utiliser les compteurs PCNT
#include "esp_timer.h"   // Pour utiliser les timers

// Constantes pour le PCNT
#define PULSE_INPUT_PIN 16       // n° GPIO qui sert au comptage d'impulsions
#define NUM_COMPTEUR PCNT_UNIT_0 // Choix du compteur, ici c'est le n°0

// Variable pour le PCNT
volatile int16_t vol_valeur_compteur = 0;

// Variables pour le Timer périodique
esp_timer_handle_t mon_timer_handle;     // Timer handle
uint64_t timer_delay = 1000 * 1000 * 10; // en µs (=10s)
volatile bool vol_fin_du_timer = false;

// Gestion des sections critiques (MUTEX)
portMUX_TYPE timerMux = portMUX_INITIALIZER_UNLOCKED;

/****** Gestionnaire du Timer ******/
void IRAM_ATTR timer_callback(void *arg)
{
    portENTER_CRITICAL(&timerMux); // début section critique
    // Lire la valeur actuelle du compteur
    pcnt_get_counter_value(NUM_COMPTEUR, (int16_t *)&vol_valeur_compteur);
    pcnt_counter_clear(NUM_COMPTEUR); // Réinitialiser le compteur
    vol_fin_du_timer = true;          // Fin d'attente du timer
    portEXIT_CRITICAL(&timerMux);     // fin section critique
}

void setup()
{
    Serial.begin(115200);

    // Configuration principale du compteur
    pcnt_config_t pcnt_config;       // structure C qui sert à configurer le compteur
    pcnt_config.unit = NUM_COMPTEUR; // Choix du compteur matériel utilisé
    pcnt_config.channel = PCNT_CHANNEL_0;
    pcnt_config.pulse_gpio_num = PULSE_INPUT_PIN;  // Pin d'entrée
    pcnt_config.ctrl_gpio_num = PCNT_PIN_NOT_USED; // Pas de signal de contrôle
    pcnt_config.pos_mode = PCNT_COUNT_INC;         // Incrémenter le compteur sur les fronts montants
    pcnt_config.neg_mode = PCNT_COUNT_DIS;         // Ne pas compter sur les fronts descendants
    pcnt_config.lctrl_mode = PCNT_MODE_KEEP;       // Garder le même mode de comptage
    pcnt_config.hctrl_mode = PCNT_MODE_KEEP;       // Garder le même mode de comptage
    pcnt_config.counter_h_lim = 0;                 // Valeur max du compteur (sur 16 bits)
    pcnt_config.counter_l_lim = 0;                 // Valeur min du compteur (sur 16 bits)

    // Appliquer la configuration principale du compteur
    pcnt_unit_config(&pcnt_config);

    // Activer le filtre anti-bruit (anti-rebond) avec la valeur maximale
    // (1023 cycles de l'horloge APB => 1023 * 12.5ns = 12.8 µs)
    pcnt_set_filter_value(NUM_COMPTEUR, 1023);
    pcnt_filter_enable(NUM_COMPTEUR);

    // RAZ et démarrage du compteur
    pcnt_counter_pause(NUM_COMPTEUR);  // Pause pour initialiser
    pcnt_counter_clear(NUM_COMPTEUR);  // Remettre à zéro la valeur du compteur
    pcnt_counter_resume(NUM_COMPTEUR); // Reprendre le comptage

    Serial.println("PCNT configuré et démarré");

    // Configuration du timer périodique
    // - se déclenche toutes les 10 secondes
    // - déclenche l'exécution de la fonction timer_callback()
    const esp_timer_create_args_t mon_timer_args = {
        .callback = &timer_callback,
        .name = "mon_timer"};
    esp_timer_create(&mon_timer_args, &mon_timer_handle);
    esp_timer_start_periodic(mon_timer_handle, timer_delay);
}

void loop()
{
    bool affichageImpulsions = false;
    int16_t nbre_impulsions = 0;

    portENTER_CRITICAL(&timerMux); // début section critique
    if (vol_fin_du_timer == true)
    {
        nbre_impulsions = vol_valeur_compteur;
        affichageImpulsions = true;
        vol_fin_du_timer = false; // réinitialiser le flag de fin de timer
    }
    portEXIT_CRITICAL(&timerMux); // fin section critique

    if (affichageImpulsions == true)
    {
        affichageImpulsions = false;
        // actions à effectuer à chaque période du timer
        Serial.println(String(nbre_impulsions) + " impulsions en 10s");
    }
    delay(1);
}
```
